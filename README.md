## Featured Projects

### Mailora

**An AI-powered email productivity application** for generating, rewriting and managing professional emails, built as a complete full-stack product: tone and length controls, reply generation, an account flow, and a searchable history of saved emails and favorite templates.

| Layer    | Technology                                   |
| -------- | -------------------------------------------- |
| Frontend | Next.js, React, TypeScript, Tailwind CSS     |
| Backend  | Next.js API routes                           |
| AI       | Gemini API, provider-based AI architecture   |
| Database | Supabase                                     |

**Capabilities:** subject and body generation · Direct / Warm / Formal tones · length control · email rewriting · reply generation · saved, searchable history · favorite emails and templates · authentication

| Backend  | Express.js, REST API, JWT authentication   |

| Database | MongoDB                                    |

**Capabilities:** typing practice · authentication · user statistics · leaderboards · achievements · AI Coach · certificate generation
